# CEE Architecture Provenance

This public repository records provenance for CEE Architecture Snapshot 01.
It is proof-only: it contains no Card/CEE production source, benchmark Runner,
benchmark script, fixtures, raw results, or private contract documents.

The private snapshot is retained outside this repository. Its payload files are
identified by the public MANIFEST.sha256; the complete manifest is committed
here and its own final SHA-256 is recorded in
MANIFEST.sha256.final.sha256.

See PROOF.md for the Card Git evidence, commit anchors, scope boundary, and the
public Benchmark v2 summary.
